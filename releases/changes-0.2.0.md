- Security: WebSocket clients must send the `token` from REAPER's instance file (`~/.reasock/instances/<pid>.json`) in `initialize` (protocol 0.3.0). The token is random each time REAPER starts, and on macOS and Linux the instance file and its folders are now readable only by your user, so other users on the machine and web pages can't connect. Scripts inside REAPER need no token.
- Examples: Python (a hotkey to copy selected items' file paths, a selection follower), an MCP server for AI agents, shell helpers with websocat, a browser dashboard, and a ReaImGui inspector panel, which also ships in the ReaPack package.
- `@techaudio/reasock` on npm: a typed TypeScript client (every method, param, result, and event typed from the OpenRPC description), with reconnect that restores actions and subscriptions after REAPER restarts, and a browser build.
